## ECMAScript Features
- `//` Regular Expressions
- `try...catch` Exception Handling
- `"use strict"` Strict Mode
- `JSON.parse()`, `JSON.stringify()` JSON to/from Regular JS Object
- `let` & `const` Declaration Keywords
- Arrow functions (=>)
- <code>``</code> Template Literals
- Default Function Parameters
- `{{}}` Destructuring
- `...` Spread/Rest Operator (function arguments & objects)
- `for...of`/`for await...of` loop
- `Promise.then().catch().finally()` Promises
- `import/export` Modules
- `Map` and `Set`
- `symbol` & `bigint` Data Types
- `**` Exponentiation Operator
- `async/await` Functions
- `Object.values()` & `Object.entries()` Object Keys/Indices & Values
- `padStart()`/`padEnd()` & `trimStart()`/`trimEnd()` Method for String Badding & Trimming
- `?.` Optional chaining
- `??` Nullish coalescing
- `globalThis` Object
- `&&=`, `||=`, `??=` Logical Assignment Operators
- `class` Keyword & `#<private_property>` Class Private Property
